# First RAFTcorr 2.0 GUI (superseded)

A simpler PySide6 interface written on 2026-11-18 before the decision to port pyALDIC's interface.
It worked end to end (its 150 offscreen tests passed then) but is no longer used: the application
is `src/raftcorr/gui` (ported from pyALDIC). Kept for reference only; the imports still say
`raftcorr.gui_basic`, so it does not run from here.
