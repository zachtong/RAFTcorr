\begin{abstract}
\noindent
This guide follows a complete RAFTcorr analysis, from installing the application to exporting
displacement and strain. Each section maps to a panel, a window or a menu of the application, so
it can be read with RAFTcorr open beside it. The two-page \emph{Quick Guide} holds the same steps
in condensed form; the last sections cover the command line, the Python library and
troubleshooting.
\end{abstract}
